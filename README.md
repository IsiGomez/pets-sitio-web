# Pets - Sitio web
Sitio web desarrollado para la actividad **Guía 1.1.3: Explorando HTML**, 
del curso DSY1104 (Desarrollo Full Stack II).

## Contexto de la actividad
Un negocio minorista de venta de artículos para mascotas necesita un sitio web 
que muestre sus productos y servicios, y dé a conocer su marca en Chile.

## Requisitos
- Página `pets.html` con tres secciones principales: historia del negocio, 
  ubicación y sucursales, y productos/servicios ofrecidos.
- Imagen de referencia en cada sección, enlazada mediante dirección absoluta.
- Títulos de secciones resaltados con etiquetas de encabezado.
- En algún lado hacer referencia a una lista ordenada (ol) o desordenada (*ul*).
- Cada sección bajo una etiqueta semántica (*'section'*/'article').
- Sección de referencias con tres enlaces de interés.

## Decisiones de configuración
- Utilice `<ul>` (lista desordenada) para los listados de productos y servicios.
- Cada sección principal fue implementada con la etiqueta semántica `<section>`.
